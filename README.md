# 我要上天

2D 生存防守游戏的 Godot 项目。角色沿用像素方向，当前出生区地图复刻指定参考图的柔和风格、颜色与 3/4 俯视效果。

当前 Demo 验证最小闭环：

- 2048 x 2048 出生区样片，由四张 1024 x 1024 底图无缝组成
- 约 35°–45°的 3/4 俯视镜头与纵深表现
- 玩家移动和镜头跟随
- 一体化玩家头像、生命条和体力条；奔跑会消耗体力，停止后恢复
- 可交互草丛；本人半透明，远端玩家不可见
- 33 种树木、枯木、蘑菇、植物和植物型危险物按固定种子随机分布
- 按参考图补全为无白边整图，保留巨像山脉、荒漠天坑、中央河流、多级台地和南部海湾的原有效果
- 山体、悬崖、深水、河流和荒漠天坑具有独立碰撞；草丛仍为可替换的独立资源

长期世界目标仍是 6144 x 6144，但不会使用一张巨型运行时纹理；地图继续按 1024 x 1024 区块扩展。

## 运行

- 引擎：Godot 4.7.2 Standard
- 脚本：GDScript
- 渲染：Compatibility
- 入口场景：`main.tscn`

用 Godot 打开项目后运行：方向键或 WASD 移动，`Shift` 跑，`Space` 跳，`C` 蹲伏，`Z` 爬行。

详细范围见 `docs/DEMO_BASELINE.md`。
