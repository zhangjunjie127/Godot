# Male character source frames

Each direction contains 16 transparent 128x128 PNG frames.
Edit the numbered frames, then run `tools/rebuild_player_male_sheets.py`.
Runtime row order: S, SE, E, NE, N, NW, W, SW.
Frames were imported from the 16-frame Godot exports on 2026-08-30.
Keep visible feet on pixel row 117.
